📦 doris-mcp-server Installation Guide

Version 1.3.1

Prerequisites

OSLinux x86_64
DorisSame host as the MCP Server, FE port 9030, passwordless admin
PortDefault 3000

Install (3 Steps)

① Extract

tar xzf doris-mcp-server-1.3.1-linux-x64.tar.gz
cd doris-mcp-server

② Configure

Edit mcp-server.toml. Usually no change is needed. To change the port:

# mcp-server.toml
[server]
mcp_port = 3000     # Change to your port

③ Start

# Foreground
bash start-mcp-server.sh

# Background
nohup bash start-mcp-server.sh > /tmp/doris-mcp.log 2>&1 &

Startup is successful when you see Uvicorn running on http://0.0.0.0:3000.

First Startup

After logging in to the Web UI as Doris admin, you can manually deploy the example workspace, which includes:

dw.orders12 sample orders
dw.users5 sample users
dw.products5 sample products
dw.dim_date365-day date dimension

5 sample metrics: total_amount, order_count, avg_amount, unique_users, user_count

The example workspace is not deployed automatically. Use the Admin-only button next to Reload to deploy it manually.

Verify

Web UI: Open http://<IP>:3000/mcp/web in a browser and log in with admin:admin.

Agent: Configure Claude Code:

claude mcp add --transport http doris http://<IP>:3000/mcp \
  --header "Authorization: Bearer admin:admin"

Then verify by asking "Check service health" in the conversation.

Common Operations

Stopfuser -k 3000/tcp
UpgradeStop → extract the new version over the old one → restart
LogsAudit log ./logs/audit.log (path is configured in [logging] in mcp-server.toml)

FAQ

Port is occupiedRun fuser -k 3000/tcp or change the port
Agent 401Token format is username:password
workspace not_readyLog in to the Web UI → Validate to see errors
Doris cannot connectConfirm FE is at 127.0.0.1:9030 and admin is passwordless
